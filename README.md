# Images Come To Life

**Author:** Arthur Goldin  

This application was developed as the final project for my **B.Sc.** degree at the **Faculty of Engineering, Bar-Ilan University**.  
The implementation utilizes the [`geometry-processing-js`](https://geometrycollective.github.io/geometry-processing-js/) and [`linear-algebra-js`](https://github.com/rohan-sawhney/linear-algebra-js) libraries, developed by **Rohan Sawhney** and **Keenan Crane**.  

The core deformation algorithm is inspired by and based on the following research papers:

- *GPU-Accelerated Locally Injective Shape Deformation* — **Renjie Chen, Ofir Weber**  
- *A Subspace Method for Fast Locally Injective Harmonic Mapping* — **Eden Fedida Hefetz, Edward Chien, Ofir Weber**  
- *Piecewise Linear Mapping Optimization Based on the Complex View* — **Björn Golla, Hans-Peter Seidel, Renjie Chen**
